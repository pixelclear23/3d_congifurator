Configurator

Maya · Arnold · OpenUSD · Omniverse Kit

A Maya shot that arrives finished.

Native USD export moves geometry and leaves the rest to hand work: shaders land grey, per-face assignments collapse, glass renders solid, lights and cameras are simply gone. Two scripts and one JSON sidecar carry the whole shot across instead.

  • 1 JSON sidecar is the whole contract
  • 5 things carried: geometry, materials, textures, lights, cameras

What survives the trip

Everything a native export leaves behind

Geometry

World-space, visible only

Hidden meshes and display-layer visibility are respected. Geometry is baked to world space, so skinned and animated rigs transfer cleanly whatever the original hierarchy. USD or Alembic.

Materials

Arnold rebuilt as USD

aiStandardSurface becomes UsdPreviewSurface: base colour, metalness, roughness, IOR, coat. Other shaders are read best-effort for base colour.

Glass & SSS

Handled, not flattened

Transmission at or above 0.25 also gets an OmniGlass MDL so RTX refracts properly; subsurface gets OmniSurface with SSS colour, radius and scale. UsdPreviewSurface stays as the non-RTX fallback.

Textures

Right colour space, first time

Rewired through UsdUVTexture. Data maps get raw, colour maps sRGB, and normal maps the tangent-space remap. Layered or procedural networks are flagged complex so you know to bake them.

Assignments

Per-face, preserved

Maya face sets such as pShape.f[0:5] become UsdGeom.Subset with materialBind, instead of collapsing to one material per object.

Lights & cameras

Recreated as UsdLux

Area and mesh lights to RectLight, directional to DistantLight, spot to SphereLight with ShapingAPI, IES and point to SphereLight, skydome to DomeLight with its HDRI. Cameras keep focal length, apertures, clipping and depth of field, with the world matrix baked per frame.

How it works

Two scripts, and one file between them

That second file is the contract between them. Geometry travels as USD or Alembic; everything a geometry format cannot carry — shaders, which face got which material, lights, cameras — travels as JSON beside it.

01

In Maya — maya_export.py

Writes the geometry, plus a <shot>.shaders.json describing every shader, assignment, light and camera.

import maya_export
maya_export.export(output_dir=r"C:/exports", name="Bag",
                   target="omniverse")   # USD geometry

# -> Bag.usd          visible geometry, baked to world space
# -> Bag.shaders.json shaders, assignments, lights, cameras
  • Frame range, step, selection-only, and static-pose options
  • bake=True flattens layered Arnold channels via render-to-texture
  • Lights and cameras get their world matrix baked per frame, so animation survives
02

In Kit — omniverse_import.py

Reads the JSON, references the geometry, rebuilds and binds materials, recreates lights and cameras, writes <shot>.omni.usda.

/World              Xform, default prim, Y-up, metersPerUnit 0.01
  /Geo              every top-level prim of the geometry file
  /Looks            UsdPreviewSurface, plus MDL where it matters
  /Lights           UsdLux + DomeLight
  /Cameras          UsdGeom.Camera
  • An omni.ui window drives it: browse, scale, new scene or append
  • Append wraps the whole import in one undo group — a single Ctrl+Z removes it
  • A lighting slider rescales every imported light live, without re-importing

The hard parts

Five failures worth knowing about

Everything glowed white

aiStandardSurface keeps emissionColor white while its weight is zero. Author emission unconditionally and every material in the shot emits. Emission is only written when the weight is actually above zero.

Half the scene went missing

AddReference(file) pulls in only the file's default object. A USD file can hold several objects at its top level, and the rest disappear with no error at all. The importer walks every top-level object and brings each one in by name.

Fuzzy matching binds the wrong mesh

Meshes are matched to assignments by exact sanitised name — transform, then shape, then shape minus a trailing Shape. A near-miss that silently paints the wrong object is worse than no binding at all.

Arnold and RTX disagree on brightness

Arnold's local-light intensities are numerically far below what RTX expects, so per-type multipliers are applied — area, point, spot, mesh and IES ×2000, sun and dome ×1 — with a global scale on top.

Kit ran yesterday's code

Kit caches modules aggressively, so a plain import can quietly run a stale copy. The launch snippets read the file from disk and exec it, which guarantees the current code runs.

A flat channel is a warning, not a bug

Layered and procedural networks cannot be expressed as one USD texture, so they are flagged complex with every file involved listed — re-export that channel baked rather than shipping something wrong.
